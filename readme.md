# Random Chat

A dark, modern static random chat demo with a 2-minute timer and online counter.

## Deploying to Vercel

1. Install the Vercel CLI or use the Vercel dashboard.
2. Point the deployment to this folder.
3. Vercel will use `index.html` as the static entrypoint.

### With Vercel CLI

```bash
vercel deploy --prod
```

The included `vercel.json` file ensures the app is served as a static site.
